# Netflix EDA — CodeAlpha Internship Task 

## Project Overview
This project performs *Exploratory Data Analysis (EDA)* on the Netflix Titles dataset.  
The aim is to discover patterns in content types, country-wise content production, and release year trends.

## Dataset
- *Dataset Name:* Netflix Titles
- *Source:* [Netflix Dataset Link](https://raw.githubusercontent.com/rfordatascience/tidytuesday/master/data/2021/2021-04-20/netflix_titles.csv)
- Contains details about TV Shows and Movies available on Netflix like title, type, country, genres, and date added.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Steps
1. Loaded and explored the dataset
2. Cleaned missing values and extracted year_added
3. Analyzed content types (Movie vs TV Show)
4. Plotted top 10 content-producing countries
5. Visualized content added over the years

## Key Insights
- Netflix has more Movies than TV Shows
- USA and India are leading countries in content production
- Peak content additions occurred after 2017
